# WordReview
一款基于单词卡片形式的简易词汇复习应用，也可用于复习其他科目。（注意：AI辅助。）

## 声明：
***本项目有AI辅助开发，若介意请不要使用。***

## 项目说明：
本项目由一个随意的想法引伸而出，目的很纯粹，就是为了提高复习时的效率，您也可以使用该项目进行语文、数学及其他学科的复习。

如何编译？

您可以选择等待维护者编译出新的可运行的exe程序或可安装的apk文件，你也可以选择将源码下载到本地自行修改、编译等（我很期待看到更好用、更美观的分支！）。

如何使用？

在词库中添加单词英文、中文与词性即可，随后就可以在复习页面进行复习了（你也可以自行编辑"words.json"文件）。

版本号规则？

A.B.C

三位纯数字，A在做出对项目修改极大的内容时+1,B在正常的优化与增添功能时+1，C在修复Bug时+1，由1.0.0版本开始。
